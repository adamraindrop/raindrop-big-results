# Raindrop — Big Results Landing Page

A single-page marketing landing page for **Raindrop** ("Ridiculous business results through big ideas"), built as a static site for review/sharing before it becomes a WordPress page on raindrop.agency.

- **Live page:** served from `index.html` at the repo root via GitHub Pages.
- **Self-contained:** all fonts (`/fonts`) and imagery (`/assets`) are bundled — no CDN or build step.
- **Responsive:** optimized for desktop and mobile (breakpoints at 980 / 760 / 680 px).
- **CTAs:** every "Talk to Us" button routes to `https://raindrop.agency/contact/`.

Implemented from a Claude Design handoff bundle.
